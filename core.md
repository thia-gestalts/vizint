# Vizint

Publish interactive explanations and exercises as source code on a static site. An author or coding agent can use whichever interaction, layout and local components fit a particular subject. The site supplies discovery, direct links, and optional learner sign-in. Keep the editorial direction open while actual entries accumulate.

A signed-in learner’s activity contributes automatically to their Thia base. Record what the interaction establishes. Exploring a model can yield an unscored engagement; practising a specific fact or skill can yield an attempt. Navigation labels and curriculum placement carry no mastery claim.

The trusted site owns local storage and Olymp. Isolate generated activity code from the full decrypted learner base. Interaktiv has a separate authoring and execution environment.
