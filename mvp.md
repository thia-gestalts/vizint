# First usable static collection

Visitors can browse a small index, open an entry by stable URL and use it without an account. Demonstrate two different interactions using existing material as a starting point. Provisional examples are the Bézier explorer and a generated rounding exercise. The exact catalog is editorial.

Moving a control point can record engagement with the Bézier topic. Answering a rounding item can record an attempt against a particular skill and include its observed outcome. A page visit alone contributes neither. Record the referenced topic/fact/skill so a different app can display it offline.

Optional Olymp sign-in automatically syncs the whole local learner base, including records and attachments outside the catalog. Gestalter can show the recently practised rounding skill after sync. Static hosting serves the built content; accounts and encrypted replication use Olymp.
